## 1. 지표 정의

전부 상삼각(3,321개 edge)에서 계산한다.

| 지표 | 정의 | 의미 |
|---|---|---|
| **r** | Pearson(pred, gt) | 연결 강약 **패턴**이 얼마나 같은 방향인가 |
| r_log | Pearson(log1p(pred), log1p(gt)) | 약한 연결까지 균등하게 본 패턴 |
| spearman | 순위 상관 | 단조 관계만 |
| **CCC** | 2·cov / (var_p + var_g + (mean 차)²) | 패턴 + **절대값**까지 맞는가 |
| RMSE / MAE | 원 단위 (가닥 수) | 절대 오차 |
| log_MAE | `|log1p(p) − log1p(g)|` 평균 | 상대 오차 |
| edge_F1 | 비영 edge 존재 일치 | 연결 유무 |
| **잔차 r** | corr(pred − 기준, gt − 기준) | **개인차**를 잡았는가 |

**잔차 r 은 leave-one-out 중심화로 계산해야 한다** (§6 참조).

블록별: ctx-ctx / ctx-sub / sub-sub, 추가로 sub-sub 중 `ss_endpoint`(끝점 지지) 와
`ss_pass_only`(통과만).
강도 구간별: 약함 <100 ≤ 중간 <1000 ≤ 강함.

## 4. subject 간 상관 — 개인차의 크기

test 31명, 465개 subject 쌍:

| 무엇끼리 | 평균 r | 표준편차 | 최소 | 최대 |
|---|---|---|---|---|
| **원본 GT 끼리** | **0.897** | 0.033 | 0.755 | 0.947 |
| 현재 방식 끼리 | 0.9991 | 0.0005 | 0.997 | 1.000 |
| bank+템플릿 끼리 | **0.9995** | 0.0003 | 0.998 | 1.000 |

로그 공간: GT 0.753 / 생성 0.988.

```
GT 개인차의 여지    : 1 − 0.897  = 0.1033
생성 개인차의 여지  : 1 − 0.9995 = 0.0005
                                   ────────
                      개인 변동이 193배 축소
```

**모델은 사실상 한 장의 행렬만 찍어낸다.** 31명에게 준 답이 서로 0.999 이상 같다.

그리고 **모델 vs GT(같은 사람) = 0.880 < GT끼리 = 0.897** 이다. 어떤 사람의 SC 를 맞히는
정확도가 **아무 다른 사람의 GT 를 가져다 쓰는 것보다 낮다.**

## 5. 개인차 표현 용량 (오라클 실험)

|---|---|---|
| 템플릿배분 + 공용bank | 0.870 | +0.129 |
| 템플릿배분 + **본인 latent** | 0.885 | **+0.390** |

부풀려져 있다. edge head 로 고르면 같은 구성이 **+0.026** 이다. 조작 효과(증분)는 유효하다.

## 6. 잔차 r 을 재는 법 — 주의

`corr(pred − train템플릿, gt − train템플릿)` 로 계산하면 **틀린다.**

```
생성(s) = P (디코더의 고정 편향, 모든 subject 에 동일) + 아주 작은 개인 성분
생성(s) − 템플릿 = (P − 템플릿) + 개인 성분
                    └── 상수 벡터가 상관을 지배한다
```

이 방식으로 재면 오라클을 다 줘도 −0.11 ~ −0.15 의 음수가 일정하게 나온다.

**올바른 방법 — leave-one-out 중심화**: GT 와 예측을 같은 방식으로, 각각 자기를 뺀
나머지 subject 평균으로 뺀다. 고정 편향이 예측 쪽 평균에도 들어가 상쇄되고,
표본 평균에 자기가 포함되어 생기는 −1/(n−1) 치우침도 사라진다.

```python
def loo_center(X):
    return X - (X.sum(0) - X) / (len(X) - 1)
residual_r = corr(loo_center(P)[i], loo_center(G)[i])
```
