# 문제 해결 계획 — 서브에이전트 운용안 (2026-09-05)

대상: `docs/PIPELINE_09_PROBLEM_INVENTORY.md` 의 축 A(개인차) / B(기하) / C(지표·절차).

## 0. 설계 원칙

1. **C 축을 먼저 고친다.** 계측이 틀린 상태로 실험하면 판정이 성립하지 않는다.
   실제로 p2 게이트는 val 8명 잡음으로 위양성을 냈고, `scripts/19_train_pipeline.py` 는
   게이트를 **출력만 하고 강제하지 않는다** (grep: `resid_r` 은 print 문에만 등장).
2. **비싼 학습 전에 싼 측정으로 가른다.** A1·A2 구현은 모델 구조 변경 + 전 phase 재학습이다.
   그 전에 "ROI 별 풀링에 개인 정보가 실제로 있는가" 를 **학습 없이** 판정한다.
3. **GPU 는 A10 1장이다.** 에이전트를 몇 개 띄우든 GPU 작업은 직렬이다.
   병렬화는 코드 작성·CPU 분석·문서에만 걸리고, GPU 구간은 기존 lock
   (`acquire_lock`, 15분 heartbeat) 으로 한 번에 하나만 돈다.
4. **모든 산출 수치는 독립 재계산으로 검증한다.** 이 프로젝트는 조용한 실패 이력이 있다.

## 2. S0 — 계측 고정 (모델 변경 없음)

기존 체크포인트로 재평가만 하므로 하루 안에 끝난다. **여기서 나온 지표 정의가 이후 모든 판정의 기준**이다.

| 에이전트 | 담당 | 산출물 | 통과 기준 |
|---|---|---|---|
| **S0-a** 지표 | C1, C5 | 보고 표를 `tier 내 r` 주지표로 재구성. CCC·총합비는 "진단값" 으로 분리 | small/mid/large r 이 표 상단에 오고 전체 r 은 참고값으로 내려간다 |
| **S0-b** 게이트 | C2, C3, C4 | `resid_r` 의 부트스트랩 CI 계산 → n=8 의 CI 폭을 수치로 못박음. 게이트를 **test 31명 기준**으로 재정의하고 `19_train_pipeline.py` 가 미달 시 **정지**하도록 강제 | n=8 CI 가 0 을 포함함을 보이고, 게이트 미달 시 실제로 멈추는 것을 단위 테스트로 확인 |
| **S0-c** 검증 | S0-a·S0-b 재계산 | 독립 스크립트로 같은 수치 재현 | 불일치 0 |

S0-a 와 S0-b 는 서로 다른 파일을 만지므로 병렬. S0-c 는 둘이 끝난 뒤.

## 3. S1 — 공간 결정 실험 (**여기서 전체 계획이 갈린다**)

**질문**: stage3 출력을 아틀라스 82 ROI 로 풀링했을 때, 어느 T1 공간이 개인 정보를 남기는가?

학습 없이 forward + ridge probe 로만 잰다.

| 조건 | 경로 | 비고 |
|---|---|---|
| (a) SyN | SyN T1 → stage3 → 82 ROI 풀링 | 아틀라스와 공간이 맞는다 |
| (b) rigid + warp | rigid T1 → stage3 → rigid→template 워프 → 82 ROI 풀링 | 개인 기하 보존 + 대응 확보 |
| (c) rigid + 전뇌 pool | 현재 구조 | **대조군** |
| (d) SyN + 전뇌 pool | 이전 구조 | 대조군 |

타깃은 LOO 중심화한 SC 잔차. train 144 로 ridge 적합 → test 31 에서 잔차 r.

**판정 기준을 미리 정한다.**

| 최고 조건의 test 잔차 r | 판단 | 다음 |
|---|---|---|
| **≥ 0.15** 이고 (c) 보다 +0.05 이상 | ROI 풀링에 정보가 있다 | S2 진행 |
| 0.05 ~ 0.15 | 신호는 있으나 약함 | S2 를 하되 목표를 하향하고 축 B 를 동시에 |
| **< 0.05** | 풀링 방식의 문제가 아니라 정보가 없다 | **A1·A2 중단.** 축 B 만 완성하고 "T1 단독 개인 예측의 한계" 를 결과로 보고 |

비용: subject 당 stage3 forward ~수초 + 143 MB. 175명(train 144 + test 31) × 4 조건.
stage3 는 조건 (a)(b) 가 같은 볼륨을 공유하므로 T1 공간당 1회만 계산해 재사용한다.

| 에이전트 | 담당 |
|---|---|
| **S1-a** | ROI 풀링 유틸 + **아틀라스 정렬 assert** (82 라벨 전부 존재, 좌우 반전 없음, 49×58×49 로 내릴 때 소실 ROI 0) |
| **S1-b** | 4 조건 forward 실행 + ridge probe (GPU lock 보유) |
| **S1-c** | 결과 독립 재계산 + 누수 점검 (**설계 행렬에 타깃이 안 들어갔는지** — 과거 ComBat 라벨 누수 재발 방지) |

S1-a 는 GPU 없이 먼저, S1-b 는 그 뒤 단독, S1-c 는 마지막.

## 4. S2 — ROI 국소 조건화 구현 (S1 통과 시에만)

```
현재:  cond = gain·a[512] + Proj(pair_vec) + mode_emb          (a 는 모든 쌍에 동일)
변경:  cond = gain·(W_i·f[i] + W_j·f[j]) + Proj(pair_vec) + mode_emb
       f[82,256] = stage3 를 아틀라스 82 ROI 로 풀링
       W_i, W_j 는 0-init → 시작 시 기존 동작과 동일
count/edge head 도 (f[i], f[j], pair_vec) 를 받는다.
```

| 에이전트 | 담당 | 검증 |
|---|---|---|
| **S2-a** | 모델 구조 변경 (`atm_adapter`, `pair_embedding`, `edge_count_head`) | 0-init 상태에서 기존 체크포인트와 **bit-exact** 동일 출력 |
| **S2-b** | 학습 경로 (VRAM·gradient checkpoint) + 캐시 전략 | 3명 100 step smoke, VRAM ≤ 20 GB, gradient 가 f 까지 흐르는지 assert |

VRAM 주의: stage3 [256,49,58,49] 를 gradient 와 함께 들고 있어야 한다. 82 ROI 풀링 결과는 84 KB 라 가볍지만
풀링 **이전** 텐서가 143 MB 이고 backward 경로가 붙는다. `torch.utils.checkpoint` 로 stage1~3 을 감싼다.

## 5. S3 — 파일럿 판정

전 phase 재학습 전에 **p2_count 하나만** 3,000 step 재실행하고 test 31명에서 `resid_r` 을 잰다.

| test resid_r | 다음 |
|---|---|
| ≥ 0.10 | 전 phase 재학습 (p0~p4). **단 A6 대응 필요** — p3·p4 에서 resid_r 이 깎이므로 magnitude 계열 손실에 개인 편차 보존 항을 넣거나 가중치를 낮춘다 |
| 0.03 ~ 0.10 | A5(edge head 개인화) 를 추가하고 파일럿 재실행 |
| < 0.03 | 중단. S1 이 위양성이었다는 뜻 → 축 B 로 전환 |

S0-b 가 만든 **강제 게이트**가 여기서 처음 실제로 작동한다.

## 6. S5 — 축 B (A 와 독립, 언제든 병렬 가능)

| 에이전트 | 문제 | 작업 | 통과 기준 |
|---|---|---|---|
| **S5-a** | B7 | weight head 를 학습 경로에 다시 연결하거나, 평가에서 제거해 학습과 일치시킨다 | 마지막 층 weight rms > 0 이거나, 평가가 가중치 없는 경로임이 명시됨 |
| **S5-b** | B5, B6 | `edge_thr` · `n_per_pair` 스윕 (추론만, 학습 없음) | GT 양성 pair 회수율 ≥ 0.85 지점의 thr 확정 |
| **S5-c** | B1, B2 | prior/디코더. 오라클 latent 로도 dice 0.167 이므로 **디코더 용량·구조**가 대상 | recon RMSE < 3.0 mm 또는 "용량으로는 안 된다" 를 측정으로 확정 |
| **S5-d** | B3, B4 | 유효 연결 0.367 과 길이 r 0.182. B1·B2 의 하류라 **S5-c 뒤에 다시 잰다** | valid_conn ≥ 0.5 |

S5-a·S5-b 는 싸고 독립이라 S0 와 동시에 돌려도 된다. S5-c 는 GPU 를 오래 쓰므로 S1·S3 과 경쟁한다 → lock 순서를 정해둔다.

## 7. 에이전트 운용 규칙

- **GPU 는 하나다.** 동시에 GPU 를 쓰는 에이전트는 1개. `acquire_lock` 를 그대로 쓴다.
  우선순위: S1 > S3 > S5-c. 나머지는 CPU 작업이라 자유롭게 병렬.
- **에이전트마다 산출물 파일과 통과 기준을 미리 준다.** "잘 됐다" 는 보고는 받지 않는다.
- **수치 보고에는 재현 명령을 붙인다.** 검증 에이전트가 같은 명령으로 재계산한다.
- **assert 를 넣는다.** 아틀라스 라벨 수, 좌우 방향, shape/dtype, NaN/Inf, 설계 행렬 누수.
- **추론에 그룹 정보(latent bank, 템플릿 배분) 를 넣는 구성은 쓰지 않는다.**

## S1 분석 프로토콜 — 실험 전 사전등록 (2026-09-06)

S1 은 A1/A2 착수 여부를 가르는 게이트이고 **중단 기준이 걸려 있다.** 결과를 보고 분석
방법을 고르면 판정이 성립하지 않으므로, 실험 전에 여기에 못 박는다. 아래에서 벗어난
분석을 하려면 그 사실과 이유를 명시한다.

### 타깃 정의 (누수 차단)
- 잔차 = `SC_s − template_train`. `template_train` 은 **train 144명 GT 평균 하나**로 고정한다.
- test subject 의 타깃 중심화에 다른 test subject 를 쓰지 않는다. LOO 중심화를 전
  subject 에 걸면 test 끼리 서로의 타깃 정보를 흘린다. 추론 시 템플릿은 train 산출물이므로
  train 평균 고정이 실제 사용 조건과도 일치한다.
- log 공간(`log1p`)과 선형 공간 둘 다 낸다. 주 판정은 log 공간.

### 특징 정의
- 조건 (a)(b): `f_s[82, C]` ROI 별 풀링. 조건 (c)(d): 전뇌 pooling `a_s[512]` (대조군).
- **train 144명에서만** PCA 를 적합해 k=32 PC 로 축소한다 (test 로 PCA 를 적합하면 누수).
- pair (i,j) 예측자 = `[u_s[i], u_s[j], u_s[i]*u_s[j]]` (u = PC 점수). 대조군은 `[u_s]` 만.

### 모델
- pair 별 ridge. train 144 샘플 / 예측자 ~96 개 → alpha 는 **train 내부 5-fold CV** 로만 고른다.
  test 를 보고 alpha 를 고르지 않는다.
- 계산량이 문제면 pair 를 층화 추출(tier×block 균등, ≥600 pair)하되 추출 시드를 기록한다.

### 판정 지표
- subject 별로 test 잔차와 예측 잔차의 상관을 pair 축에서 계산 → **31명 중앙값**을 보고한다
  (평균은 이상치에 끌린다). 부트스트랩 95% CI 를 함께 낸다.
- tier 내부로도 쪼개 본다 (C1 과 같은 이유 — 전체 pair 값은 배율차에 지배될 수 있다).

### 필수 대조군 (없으면 결과를 믿지 않는다)
1. **subject 라벨 셔플**: 특징만 subject 간 무작위 재배치. r ≈ 0 이 나와야 한다.
   0 이 아니면 파이프라인에 누수가 있다.
2. **전뇌 pooling (c)(d)**: ROI 풀링의 이득이 pooling 변경에서 온 것인지 확인.
3. **머리 크기 단일 회귀**: 뇌 부피(또는 T1 총 강도) 하나만으로 같은 probe 를 돌린다.
   ROI 풀링이 이걸 못 넘으면 "개인차" 가 아니라 크기 효과다.

### 사전등록 판정 (PIPELINE_08 §4 P2 분기와 동일한 눈금)
| 최고 조건의 test 잔차 r (중앙값, log) | 판정 | 다음 |
|---|---|---|
| **≥ 0.15** 이고 (c) 대비 +0.05 이상 | 국소 조건화에 신호 있음 | S2 진행 |
| 0.05 ~ 0.15 | 약한 신호 | S2 진행 + 목표 하향, 축 B 동시 |
| **< 0.05** | 구조가 아니라 정보가 없다 | **A1/A2 중단.** 축 B 완성 후 "T1 단독 개인 예측의 한계" 를 결과로 보고 |

대조군 1(셔플)이 0 에서 유의하게 벗어나면 **어떤 값이 나오든 판정을 보류**하고 누수를 먼저 잡는다.
