## 0. 한 문단 요약

목표는 T1 에서 **subject-specific** tractogram/SC 를 만드는 것이다. 현재 모델은 SC r 0.788 을 내는데,
같은 test 31명에서 **훈련 144명 GT SC 평균(상수, T1 을 아예 안 봄)이 r 0.945** 를 낸다. 31명 전원에서
모델이 이 상수를 못 넘는다. 즉 보고되던 0.788 은 전부 그룹 성분이고, 개인 성분 기여는 0 이다
(`residual_r` 0.023 ± 0.162). 원인 후보를 개인차 축에서 3×3 으로 전수 측정했고 유의한 칸은 하나
(전역 anatomy → SC 카운트 r 0.101)뿐이며 그것은 **머리 크기**다. 다만 그 프로브는 *다른 목적으로 학습된
frozen 인코더* 에 *선형* readout 을 건 것이라, "T1 에 정보가 없다"는 데이터 수준 주장을 검정한 것은 아니다
(§7).

## 6. 개인차 축 — 3×3 전수 측정

세 타깃 × 세 feature 위치. 전부 subject 단위 5-fold CV, pair 평균은 훈련 fold 로만 계산(누수 방지),
순열검정 200회. 귀무 sd 0.008~0.009 → **r ≳ 0.02 면 검출됐을 검정력.**

| 타깃 ＼ feature | 전역 anatomy512 | 끝점 ROI 512 | 경로 풀링 256 |
|---|---|---|---|
| latent 조건평균 (**모양**) | +0.075 | +0.011 | −0.014 (p=0.26) |
| GT SC 카운트 (**세기**) | **+0.101** | +0.053 | −0.007 (p=0.20) |
| 경로 변위 mm (**위치**) | −0.007 | +0.002 | −0.017 (p=0.285) |

유의한 칸은 하나뿐이고, 그 +0.101 은 S1-b 의 머리부피 단독 0.102 를 **독립 재현**한 것이다
(다른 스크립트·다른 pair 집합·다른 CV). 즉 지금까지 이 프로젝트에서 측정된 개인 신호는 전부
**머리 크기 하나**로 설명된다.

## 7. 확정된 것 / 확정 안 된 것

### 측정으로 확정
1. **현재 모델은 개인 정보를 전혀 안 읽는다.** `residual_r` 0.023±0.162, 0/31 템플릿 미달,
   예측 subject 간 상관 0.99914, 평균 예측으로 전원 대체해도 SC r 변화 −0.0002.
2. **frozen feature + 선형 readout 으로는 안 읽힌다.** 순열 귀무 sd 0.008~0.009 에서 −0.017~+0.011.
3. **디코더는 병목이 아니다.** 오라클 pair 0.524 vs 생성 0.068 → 격차는 latent 샘플링.
4. **CCC 0.090 은 모델 실패가 아니라 스케일 아티팩트.** 상수 k=11.2 로 0.746.
5. **모델이 cross-subject 기준선보다 못하다** (SC 0.788 vs 0.841, dice 0.553 vs 0.574).

### 확정되지 **않은** 것 — 여기가 중요하다
1. **"T1 에 개인 정보가 없다"는 검정한 적 없다.** 프로브가 쓴 feature 는 *streamline VAE 복원용으로
   학습된* 인코더의 출력이다. 개인차 supervision 을 한 번도 받지 않았다. 정보가 T1 에 있는데
   인코더가 안 담은 경우와 T1 에 없는 경우를 프로브는 구분하지 못한다.
2. **선형 readout 상한일 뿐이다.** ridge 는 비선형 매핑의 상한이 아니다.
3. **잔차가 재현 가능한 신호인지 모른다.** test-retest 미측정. `DBS_ONOFF_tracto/` 는 sub-01·sub-03
   2명만 ses-02 가 있고 **T1 만 있으며 tract 은 `pending`** 이다. 잔차가 tractography 잡음이면
   아무도 못 맞히고, 신호면 프로브 음성은 인코더 탓일 수 있다. 지금은 둘을 구분할 수 없다.
4. **잔차를 타깃으로 end-to-end 지도학습을 돌린 적이 없다.** count head 는 SC *절대값* 에 학습됐다.

> 앞서 "현재 데이터로 달성 불가가 측정으로 확정됐다"고 쓴 것은 **과장이었다.**
> 프로브 상한을 데이터 상한으로 바꿔치기한 것이다. 옳은 문장은
> **"현재 모델·현재 feature·선형 readout 에서 0 이고, 데이터 수준 주장을 검정하는 실험은 아직 안 돌렸다."**

## 8. 남은 실행 항목

### 개인차 축 — 가설 검정 (아직 안 한 유일한 직접 실험)
1. **잔차 타깃 end-to-end 학습.** SC 절대값 대신 `SC − 그룹템플릿` 을 예측하도록 count head 를 학습.
   supervision 을 직접 걸었는데도 0 이면 데이터 주장이 비로소 근거를 갖고, 0 이 아니면
   프로브 음성이 인코더 탓이었다는 뜻이다. **어느 쪽이든 지금 모르는 걸 알게 된다.**

### 그룹 기하 축 — 회수 가능한 r 0.157 이 놀고 있다
2. **prior 온도 스윕** `z = mu + s·sigma·eps`, s ∈ [0.2, 1.0]. 학습 0. B5(sigma 1.0 vs GT 0.18) 직격.
3. **가닥 수 보정** k=11.2. CCC 0.090 → 0.746 (subject 최적 0.762). 즉시.
4. **후처리 필터** GM/WM 마스크 + `minlength 20` (상류 ATM 의 `tckedit` 대응). overreach 1.407 직격.

### 정보를 실제로 더하는 길 (현재 막힘)
5. **DWI/FOD 입력 추가** — 로컬에 raw DWI/`.fib` 없음.
6. **GT 를 native space 로** — DSI Studio 필요. QSDR 정규화가 지운 개인차를 되살리는 유일한 길.

### 잡정리
- PBS **82900** (`atm_route`, base_g, 24h) 가 큐에 있고 `configs/pipeline_route.yaml` 은
  폐기된 ROUTE 파이프라인을 가리킨다. 스케줄되면 H100 24시간이 낭비된다. 취소 또는 1번으로 재지정 필요.
